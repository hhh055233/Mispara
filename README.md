# אתר המספרה — Firebase + GitHub + Vercel

האתר כולל ממשק בעברית (RTL), תורים, שירותים ומחירים, כניסת מנהל, הגדרות אתר וכפתור פרסום `index.html` ל-GitHub.

## לפני שמפרסמים

**אל תשתמשו באתר עם לקוחות אמיתיים לפני שסיימתם את שלבי האבטחה והבדיקה.** הקוד הוא בסיס התחלתי; צריך לבדוק תורים כפולים, כללי Firestore, הרשאות ואופן הטיפול בפרטי לקוחות.

## 1. יצירת חשבון מנהל ב-Firebase

1. פתחו Firebase Console > Authentication > Users.
2. לחצו Add user והגדירו דוא"ל וסיסמה חזקה שרק המנהל יודע.
3. פתחו את המשתמש החדש והעתיקו את ה-UID שלו.
4. החליפו בקובץ `index.html` את `REPLACE_WITH_ADMIN_UID` ב-UID האמיתי.
5. החליפו גם בקובץ `firestore.rules` את `REPLACE_WITH_ADMIN_UID` באותו UID.
6. ב-Firebase Console > Firestore Database > Rules, הדביקו את תוכן `firestore.rules` אחרי החלפת ה-UID ולחצו Publish.
7. ב-Firebase Authentication > Settings > Authorized domains, הוסיפו את דומיין Vercel אחרי הפריסה.

אין להפעיל הרשמה ציבורית למנהלים.

## 2. העלאה ל-GitHub

1. צרו repository חדש ב-GitHub.
2. העלו את כל הקבצים והתיקייה `api/` בדיוק במבנה שב-ZIP.
3. ודאו ש-`index.html` נמצא בשורש המאגר.

## 3. חיבור Vercel

1. ב-Vercel בחרו Add New > Project וייבאו את המאגר מ-GitHub.
2. לפרויקט סטטי עם פונקציית API אין צורך ב-build command. השאירו את הגדרות ברירת המחדל או בחרו Other לפי המסך.
3. לאחר הפריסה, הוסיפו ב-Project Settings > Environment Variables את המשתנים הבאים לכל סביבה שבה תפרסמו:

- `FIREBASE_WEB_API_KEY` — ערך `apiKey` מהגדרות Firebase Web.
- `ADMIN_UID` — ה-UID של משתמש המנהל ב-Firebase Authentication.
- `GITHUB_TOKEN` — Fine-grained personal access token של GitHub, מוגבל למאגר הזה בלבד, עם הרשאת Contents: Read and write. שמרו אותו בסוד ואל תכניסו אותו ל-HTML.
- `GITHUB_OWNER` — שם המשתמש או הארגון ב-GitHub שמחזיק במאגר.
- `GITHUB_REPO` — שם המאגר.
- `GITHUB_BRANCH` — שם הענף, בדרך כלל `main`.

4. אחרי הוספת משתני הסביבה בצעו Redeploy.

## 4. חיבור Firebase

הגדרות אפליקציית Web הוטמעו בקובץ `index.html` על בסיס פרטי הפרויקט שסופקו. `apiKey` של Firebase Web אינו סוד בפני עצמו; האבטחה נקבעת באמצעות Authentication וכללי Firestore.

## 5. כפתור פרסום קוד

לאחר התחברות כמנהל, פתחו את לשונית "פרסום קוד", לחצו "טען קוד האתר", ערכו בזהירות ולחצו "פרסם קוד ל-GitHub". הפעולה מחליפה את `index.html` במאגר; Vercel אמור לזהות את ה-commit ולהתחיל פריסה.

**חשוב:** בצעו גיבוי לפני פרסום. כפתור זה מפרסם קובץ HTML אחד בלבד; הוא לא משנה קבצים אחרים במאגר.

## 6. WhatsApp

מספר ברירת המחדל באתר הוא 0509541350, וקישורי WhatsApp נוצרים בפורמט בינלאומי. לאחר הזמנת תור נפתחת הודעה מוכנה; הלקוח צריך ללחוץ Send בתוך WhatsApp. זו לא שליחה אוטומטית.

## הערות תפעוליות ואבטחה

- הזמנת תור משתמשת בבדיקת זמינות בצד הלקוח ולא מבטיחה נעילה אטומית של שעה; שני לקוחות עלולים לנסות להזמין את אותה שעה בו-זמנית. לפני שימוש מסחרי מומלץ להעביר יצירת תורים לשרת/Cloud Functions עם טרנזקציה.
- כללי Firestore מאפשרים יצירת תור לאורחים אך לא מאפשרים להם לקרוא את רשימת התורים. ניהול הרשימה מוגבל ל-UID המנהל.
- כדי להגן מפני ספאם, כדאי להוסיף App Check או הגבלת קצב בצד שרת.
- תמונות/העלאת רקע אינן מועלות כרגע ל-Storage; שינוי צבעים, שם, שעות, WhatsApp ושירותים נשמר בהגדרות Firestore.
- אין לשתף סיסמת מנהל או `GITHUB_TOKEN`.
