בגרסה הזו אין סנכרון אוטומטי לחשבון Google. אחרי קביעת תור אפשר לפתוח טופס אירוע מוכן ב־Google Calendar ולהוסיף אותו ידנית לחשבון Google שבו אתם מחוברים. לא נדרשים מפתחות Google או שרת נוסף.

פרסום קוד מבצע commit של index.html למאגר GitHub שמוגדר ב־Vercel, ואז Vercel בונה גרסה חדשה. נדרשים משתני סביבה והתחברות מנהל. שמרו עותק לפני פרסום.

אל תכניסו לקוד סיסמאות או מפתחות פרטיים. טוקן GitHub חייב להישמר ב־Vercel בלבד.
